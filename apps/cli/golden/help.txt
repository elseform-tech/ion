Usage: ion [options] [command]

Options:
  --json                             Machine-readable output
  -h, --help                         display help for command

Commands:
  daemon                             Start, stop or check the ion service
  status                             Is ion running, and how many projects
  projects                           Your projects
  ask [options] <text>               Ask a coding agent to do something in a
                                     project
  questions                          Questions waiting on you
  answer [options] <id> <answer...>  Answer a question: a choice's number, or
                                     your own words
  chats                              Your chats
  ions                               ion and your projects' ions
  routines                           What your projects' ions do on a schedule
  suggestions                        What ion suggests
  memory                             What ion remembers
  todo                               Your to-dos
  decisions                          Your answers, and what came of them
  agents                             Coding agents and their models
  mcp                                MCP servers ion gives every agent (each
                                     agent manages its own)
  skills                             Skills ion gives every agent (each agent
                                     manages its own)
  hooks                              Hooks on ion's events, for every agent
                                     (each agent manages its own)
  settings                           Notifications and each agent's switches
  help [command]                     display help for command

---

Usage: ion daemon [options] [command]

Start, stop or check the ion service

Options:
  -h, --help      display help for command

Commands:
  start           Start ion
  stop            Stop ion
  status          Show the process and port
  help [command]  display help for command

Usage: ion projects [options] [command]

Your projects

Options:
  -h, --help                    display help for command

Commands:
  ls                            List your projects
  add [options] <path>          Add a folder
  new <name>                    Make a new project
  rename <id> <name...>         Show a project under a new name
  agent [options] <id> [agent]  What the chats its ion starts run on
  remove <id>                   Take a project out of ion (its folder stays)
  help [command]                display help for command

Usage: ion ask [options] <text>

Ask a coding agent to do something in a project

Options:
  -p, --project <id>  Project
  --chat <id>         Continue a chat
  --agent <id>        claude-code, codex, grok-build or opencode (default: the
                      chat's, else one signed in)
  --model <model>     Model
  --effort <level>    low, medium, high or max
  --access <mode>     auto (ion decides) or full
  --no-memory         Don't remember this chat
  -h, --help          display help for command

Usage: ion mcp [options] [command]

MCP servers ion gives every agent (each agent manages its own)

Options:
  -h, --help                      display help for command

Commands:
  search <name>                   Look it up in the official MCP Registry
  add [options] <name> [args...]  Add one, off
  import [options] [names...]     Bring yours in from your other agents, off
  ls                              List them
  verify <name>                   Check it, and where it came from
  doctor [name]                   Find problems, never starting one that's off
  remove <name>                   Remove it
  help [command]                  display help for command

---

Usage: ion mcp add [options] <name> [args...]

Add one, off

Options:
  --command <cmd>         What it runs
  --arg <arg>             One argument (repeat it)
  --env <NAME=${NAME}>    An env variable (repeat it)
  --url <url>             Its URL, for a remote one
  --header <Name: value>  A header (repeat it)
  --from <id or link>     Its registry id or source link
  -h, --help              display help for command

---

Usage: ion mcp import [options] [names...]

Bring yours in from your other agents, off

Options:
  --list                  Only list them
  --all                   All of yours (not ones in a project's own files)
  --from <agent or file>  One agent's (claude-code, codex, opencode,
                          grok-build), or a project's file (shop:.mcp.json)
  -h, --help              display help for command

Usage: ion settings [options] [command]

Notifications and each agent's switches

Options:
  -h, --help                  display help for command

Commands:
  briefing [when]             ion's daily briefing: on, off, or a time (08:30)
  quiet [hours]               Quiet hours: on, off, or from-to (22:00-08:00)
  notify <project> [level]    How much a project notifies: all, needs-me, digest
                              or muted
  avoid <agent> [on|off]      Avoid an agent unless you ask for it
  own-tools <agent> [on|off]  Let an agent use its own tools too (on by default)
  help [command]              display help for command
