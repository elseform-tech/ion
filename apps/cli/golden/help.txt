Usage: ion [options] [command]

Options:
  --json                Machine-readable output
  -h, --help            display help for command

Commands:
  daemon                Start, stop or check the ion service
  status                Is ion running, and how many projects
  projects              Your projects
  ask [options] <text>  Ask a coding agent to do something in a project
  needs                 What's waiting on you
  chats                 Your chats
  memory                What ion remembers
  harnesses             Coding agents and their models
  help [command]        display help for command

Usage: ion ask [options] <text>

Ask a coding agent to do something in a project

Options:
  -p, --project <id>  Project
  --chat <id>         Continue a chat
  --harness <id>      claude-code, grok-build or opencode (default:
                      "claude-code")
  --model <model>     Model
  --effort <level>    low, medium, high or max
  -h, --help          display help for command
